🧮 Calculadora de IMC

Sistema de cálculo y gestión del Índice de Masa Corporal (IMC), desarrollado en Python y SQLite.

📌 Descripción

Este proyecto permite registrar personas y calcular su IMC a partir de su peso y altura.

El sistema también permite almacenar y administrar los registros mediante una base de datos SQLite.

🚀 Funciones

- Registrar personas
- Calcular el IMC automáticamente
- Clasificar el IMC
- Ver historial de registros
- Buscar personas por nombre
- Editar registros
- Eliminar registros
- Mostrar estadísticas
- Validar los datos introducidos
- Almacenar información mediante SQLite

🛠️ Tecnologías utilizadas

- Python
- SQLite
- SQL
- GitHub

▶️ Cómo ejecutar

1. Tener Python 3 instalado.
2. Descargar o clonar este repositorio.
3. Ejecutar:

python main.py

La base de datos "imc.db" se crea automáticamente al ejecutar el programa.
